## Security architecture

- Public routes keep the static CSP required for static generation, ISR, and CDN caching.
- `/admin` routes receive a unique per-request nonce through `proxy.ts`.
- Admin `script-src` and `style-src` do not contain `'unsafe-inline'`.
- The nonce-bearing policy is forwarded to Next.js and mirrored on admin rendering, redirects, `403`, and fail-closed `503` responses.
- The root layout does not call `headers()` and therefore does not force the public site into dynamic rendering.
- Public production `upgrade-insecure-requests` remains controlled by the shared deployment resolver.
